# Personal Portfolio Webpage — Web Development Week 1

## 📌 Project Overview
This repository contains the **Week 1 Web Development Assignment**. The project is a clean, modern, and fully responsive personal portfolio webpage constructed using **Semantic HTML5** and **CSS3**.

---

## 🛠️ Assignment Objectives & Features
* **Semantic Structure**: Built using HTML5 structural tags (`<header>`, `<nav>`, `<section>`, `<footer>`).
* **Core Sections**:
  * **Header/Hero**: Introduction, tagline, profile photo, and call-to-action buttons.
  * **About Me**: Professional summary and background.
  * **Education**: Academic credentials timeline (MCA & BCA degrees).
  * **Skills**: Grid view of technical skills including Python, Data Analysis, Machine Learning, Web Development, and SQL.
  * **Contact Section**: Interactive contact form and direct profile links (Email, GitHub, LinkedIn).
* **Responsive Layout**: Styled with modern CSS Flexbox and Grid, making it seamless on desktops, tablets, and mobile devices.
